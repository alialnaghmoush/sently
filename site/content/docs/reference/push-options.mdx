| Field | Type | Required |
| --- | --- | --- |
| `subscription` | `PushSubscription` | yes |
| `title` | `string` | yes |
| `body` | `string` | yes |
| `data` | `Record<string, unknown>` | no |
| `icon` | `string` | no |
| `ttl` | `number` | no |
| `messageId` | `string` | no |

A subscription contains `endpoint`, `keys.p256dh`, and `keys.auth`.
